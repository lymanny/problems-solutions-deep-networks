# 🧠 Problems and Solutions in Deep Networks

Beginner-friendly Python examples for common problems and solutions in deep neural networks.

## 📚 Topics

- ⚠️ Vanishing Gradient
- 📉 Underfitting
- ⚡ ReLU (Rectified Linear Unit)
- 📊 Batch Normalization
- 📐 Layer Normalization
- 🔗 Skip Connection
- 🖼️ Data Augmentation
- 🎯 Dropout

## 🐍 Python Examples

The project includes simple examples for:

- Understanding how gradients can become very small
- Showing underfitting with a simple model
- Using ReLU and understanding Dying ReLU
- Using Batch Normalization
- Using Layer Normalization
- Creating a Skip Connection
- Applying image Data Augmentation
- Using Dropout during training
